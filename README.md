# TodoListApp

A simple to-do list app built while learning React Native and Expo.

## Features

- Add new to-do items
- Mark items as complete/incomplete
- Delete items
- Live count of total and completed tasks

## Stack

- [Expo](https://expo.dev/) (React Native)
- TypeScript
- `@expo/vector-icons` (Ionicons)
- Jest + React Native Testing Library

## Getting Started

```bash
npm install
npx expo start
```

Then scan the QR code with [Expo Go](https://expo.dev/go) on your device, or press `i` / `a` to open in an iOS/Android simulator.

## Running Tests

```bash
npm test
```
